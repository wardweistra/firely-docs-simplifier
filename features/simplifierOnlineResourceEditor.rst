Online Resource Editor
======================

The Online Resource Editor is a revolutionary zero-install tool integrated directly into Simplifier.net that enables you to create and edit FHIR resources and FHIR Shorthand (FSH) files directly in your browser. This feature eliminates the need for local software installation while providing a powerful, user-friendly interface for FHIR development.

Overview
--------

The Online Resource Editor combines the power of visual FHIR resource editing with support for FHIR Shorthand, offering developers flexibility in choosing their preferred authoring approach. Whether you prefer visual modeling with Forge-style interfaces or code-based development with FSH, the Online Resource Editor accommodates both workflows.

FHIR Shorthand Integration
--------------------------

The Online Resource Editor provides comprehensive support for FHIR Shorthand (FSH), a domain-specific language for defining FHIR artifacts. FSH allows you to:

- Define FHIR profiles, extensions, and value sets using human-readable syntax
- Create implementation guides more efficiently
- Maintain version control of your FHIR definitions
- Collaborate with teams using familiar text-based workflows

**FSH Capabilities**
  - Full FSH syntax support
  - Real-time compilation to FHIR JSON/XML
  - Validation against FHIR specifications
  - Package dependency management
  - Multi-file FSH project support

Getting Started
---------------

**Accessing the Editor**

1. Log into your Simplifier.net account
2. Navigate to your project or create a new one
3. Click on the "Online Resource Editor" option
4. Start creating or editing your FHIR resources and FSH files

**Creating FSH Files**

1. In the Online Resource Editor, select "New File"
2. Choose "FHIR Shorthand (.fsh)" as the file type
3. Start writing your FSH definitions using the built-in editor
4. Save and compile your FSH files directly in the browser

**Working with Dependencies**

- Add package dependencies through the project settings
- Reference external profiles and value sets in your FSH files
- Automatic resolution of dependencies during compilation

Forge vs FSH: Choosing Your Approach
------------------------------------

The Online Resource Editor supports both visual modeling (similar to Forge) and code-based authoring with FSH. Consider these factors when choosing your approach:

**Use Forge-style Visual Modeling When:**
  - You prefer graphical interfaces
  - Working with less technical team members
  - Need quick visual overview of profile structures
  - Creating simple to moderate complexity profiles

**Use FHIR Shorthand When:**
  - You prefer text-based, declarative approaches
  - Working with complex profiling scenarios
  - Need version control and diff capabilities
  - Collaborating with developers familiar with code
  - Building implementation guides with multiple related artifacts

**Hybrid Approach:**
  - Switch between visual and code views as needed
  - Use visual tools for exploration and FSH for final implementation
  - Leverage strengths of both approaches within the same project

Best Practices

**Project Organization**
  - Use meaningful file names for your FSH files

**Collaboration**
